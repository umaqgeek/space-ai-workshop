# Malaysia outline

`malaysia.geojson` contains the Malaysia feature from Natural Earth’s 1:10m
Admin 0 Countries dataset. Geometry is preserved; source properties are reduced
to attribution. Retrieved on 2026-10-29.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson

License: public domain. https://www.naturalearthdata.com/about/terms-of-use/

The browser uses the same coordinate projection for polygons and record markers.
The two panels use separate scales, with longitude adjusted at 4° N. This is a
small-scale reference map, not a survey or an authoritative boundary service.
The outline is bundled locally; no map tile service or API key is required.


Markers come from the current merged dataset (bundled observations plus saved
edits and CSV additions). Data Explorer search and application filters determine
which locations appear; collapsing an application group does not filter the map.
The importing browser refreshes markers after a successful CSV upload. Other
open browsers must reload to get the current records. Imports do not modify the
bundled outline or its projection; locations outside the displayed Malaysia
panels may fall outside the map viewport.
